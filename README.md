# AI Hub

Static HTML collection of AI tools, courses, and references. Shared styles live in `css/`, shared scripts in `js/`. The directory (including Evaluation and the Site Admin usability suite) is defined in `js/hub.js`.

**Live site:** https://joembraun.github.io/ai-hub/

**Site Admin:** [Usability Suite Run](admin-hub.html) — recorded checks that the Evaluation page and every other hub are reachable from navigation.

## Deploy

GitHub Pages publishes this site.

1. Merge to `main`, or run **Actions → Deploy GitHub Pages → Run workflow**.
2. One-time: **Settings → Pages → Source → GitHub Actions**.

Until that setting is switched, Pages continues to publish from the `main` branch.
