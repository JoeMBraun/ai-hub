Start Here

A simple order if you are new. Skip ahead when you already know a step.

  1. Chatbots — try a chat interface and notice what it does well or poorly.
  2. Prompting — learn the patterns that shape model behavior.
  3. Architecture — see how chat, tools, and data fit together.
  4. Agents — when the model needs to take actions, not just answer.
  5. Evaluation — measure whether the system is good enough.
  6. Security — treat model input and tools as untrusted by default.
  7. Deployment — run it for real users.
