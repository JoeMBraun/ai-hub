Choose an AI

A job-based path into the Chatbot Hub. Not a leaderboard.

Who this is for

You want a chat interface to write, research, or think with, and you do not want a numeric ranking of models.

Short answer

Start from the job. Open the matching product in the Chatbot Hub. Vendor names and versions on that hub are labeled Needs review until someone verifies them.

Decision tree

  1. If you need careful writing or long documents, start with the Anthropic entry on the Chatbot Hub.
  2. If you need a general consumer chat with built-in tools, start with the OpenAI entry.
  3. If you live in Google Docs / Gmail / Search, start with the Google entry.
  4. If you want a live web / X-oriented chat, start with the xAI entry.
  5. If you must keep data on your machine, skip chat APIs and use the local models guide.

Default

Pick one interface, try a real task for a week, and only then compare. Switching every day hides whether the tool fits.

Alternatives

  • Meta and other consumer apps on the Chatbot Hub if your contacts already live there.
  • Perplexity-style search chat when the job is sourced web answers more than drafting.
  • A coding harness instead of a chatbot when the job is changing a repository — see choose a coding tool.

Tradeoffs

Steps

  1. Write the job in one sentence (example: “rewrite this policy for staff”).
  2. Open Chatbot Hub and use the “How to choose” table.
  3. Run the same job in at most two products.
  4. Keep notes on citations, refusals, and whether it followed your constraints.
