Build your first AI agent

An agent is a loop with tools. Start smaller than a multi-agent diagram.

Who this is for

You can already prompt a model. You now need it to call tools or edit a system of record.

Short answer

One agent, few tools, a step budget, logs, and a human gate for side effects. Use ReAct before graphs of agents.

Decision tree

  1. If a single answer with no tools is enough, stay on a chatbot.
  2. If the model only needs documents, build RAG first.
  3. If the next action depends on a tool result, build a ReAct loop.
  4. If two specialists must talk, add a supervisor only after the single loop is reliable.

Default

ReAct with one worker. Compare patterns on the Agents Hub: ReAct, Reflexion (retry with self-critique), Plan-Act-Reflect, Human-in-the-Loop.

Alternatives

  • Fixed workflows (no model choosing the next tool) when the path is known.
  • HITL-only drafts when you are not ready to grant tools.

Tradeoffs

PatternUse whenAvoid when
ReActTools + observationsNo tools
ReflexionCheap retries and a checkerUnsafe or expensive retries
Supervisor + workersClear specialtiesYou cannot debug one agent yet
Human-in-the-loopIrreversible actionsEvery token would need a click

Steps

  1. Write the success check (test pass, ticket field set, file exists).
  2. List tools with schemas and deny everything else.
  3. Implement think → act → observe with a max step count.
  4. Log the trace. Add approval for writes.
  5. Evaluate on a handful of tasks with known outcomes.
Agent Architecture
Planner, tools, memory, stop conditions
ReAct Pattern
Think, act, observe
