Run AI locally

Local inference is a hardware and runtime choice. Exact requirements vary by quantization, context length, and runtime.

Who this is for

You want a model on your machine for privacy, cost, or offline use. You are not looking for a fake VRAM leaderboard.

Short answer

Install a runtime (Ollama or LM Studio are the usual first try), pull a small model first, then scale up only if quality is not enough. Confirm sizes on the vendor page — this site does not invent GB figures.

Decision tree

  1. If you want a GUI and no CLI, start with LM Studio on the Local Models Hub.
  2. If you want a local HTTP API, start with Ollama.
  3. If you want a ChatGPT-like UI on top of a local API, look at Open WebUI.
  4. If you need frontier quality and have no suitable GPU/RAM, use a cloud chatbot instead.

Default

Small quantized model + Ollama + one test prompt. Increase size only after it runs stably.

Hardware tiers (indicative, not guarantees)

Rough machineWhat to try first
CPU laptop, 8–16 GB RAMSmallest advertised quantized models; expect slow tokens
16–32 GB RAM, no dedicated GPUMid-small quantizations; keep context short
Consumer GPU with modest VRAMGPU-offloaded quantizations the runtime documents
High VRAM workstationLarger weights if the vendor card says they fit

Exact requirements vary by quantization, context length, and runtime. Treat any GB number you see elsewhere as Needs review until you measure it on your machine.

Alternatives

  • Cloud APIs when quality or speed matters more than locality.
  • Hybrid: local drafts, cloud for hard prompts (see Hybrid Routing).

Steps

  1. Open Local Models Hub and pick a runtime card.
  2. Install from the vendor site, not a random script dump.
  3. Run the smallest model they document.
  4. If it works, try a larger model until RAM/VRAM pressure shows up.
  5. Point a harness at the local API only after chat works.
