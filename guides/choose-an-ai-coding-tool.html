Choose an AI coding tool

A workflow-based path into the Harness Hub. Not a ranking of IDEs.

Who this is for

You write software and want an assistant in the editor, terminal, or browser. You do not need a scoreboard.

Short answer

Match the tool to where you already work. The Harness Hub lists products; this page tells you which row to start with.

Decision tree

  1. If you want an agent in the terminal over a real repo, start with Claude Code or Codex on the Harness Hub.
  2. If you want an AI-native editor, start with Cursor, Windsurf, or similar IDE rows.
  3. If you want completions inside VS Code or JetBrains you already use, start with GitHub Copilot, JetBrains AI, or Tabnine.
  4. If you want a cloud VM or browser app that scaffolds a project, start with Replit, v0, Bolt, or Lovable.
  5. If you need the model local, prefer OpenCode / local-capable rows and the local guide.

Default

Use the assistant inside the editor you already know, on a small branch, with tests running. New IDEs are optional after that works.

Alternatives

  • Chat-only coding in ChatGPT or Claude when you are learning an API, not editing a large repo.
  • Open-source harnesses (OpenCode, SWE-agent) when you must see the loop.

Tradeoffs

If you needWatch for
Deep repo agentsUnreviewed diffs and secret files in context

Steps

  1. Name the workflow: complete a line, edit a repo, or generate a prototype.
  2. Open the matching section on Harness Hub.
  3. Give the tool a failing test or a precise file list.
  4. Review every diff. Do not merge agent output you did not read.
